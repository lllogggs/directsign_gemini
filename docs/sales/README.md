# 연락미 영업용 소개서

이 폴더는 광고주와 인플루언서에게 바로 보낼 수 있는 소개서 파일을 보관합니다.

- `advertiser-introduction.html`: 광고주·대행사용 6페이지 화면 중심 소개서
- `influencer-introduction.html`: 인플루언서·크리에이터용 소개서
- `assets/yeollock-advertiser-dashboard.png`: 실제 광고주 대시보드 캡처
- `assets/yeollock-contract-builder.png`: 실제 계약서 작성 화면 캡처
- `assets/yeollock-contract-admin.png`: 실제 광고주 계약 상세 화면 캡처
- `assets/yeollock-contract-completed-admin.png`: 실제 완료 계약 조회 및 PDF 다운로드 화면 캡처
- `assets/yeollock-influencer-contract.png`: 실제 인플루언서 모바일 계약 검토 화면 캡처
- `assets/yeollock-advertiser-screen.png`: 광고주 화면 캡처
- `assets/yeollock-influencer-screen.png`: 인플루언서 화면 캡처

광고주용 자료는 텍스트를 줄이고 실제 화면 위에 짧은 빨강 박스 캡션을 붙이는 방식으로 구성합니다. 핵심 메시지는
계약서를 쉽게 만들고 검토 링크로 바로 발송한 뒤, 수정 요청과 전자서명 증빙을 계약별로 관리할 수 있다는 점입니다.

브라우저에서 HTML 파일을 열고 인쇄 메뉴에서 PDF로 저장하거나
`node scripts/capture-sales-assets.mjs`를 실행하면 메일 첨부용 PDF로 사용할 수 있습니다.
